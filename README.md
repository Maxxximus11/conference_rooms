# Conference Room Booking 

REST API для управління орендою конференц-залів. Написаний на ASP.NET Core з використанням бази даних PostgreSQL.

## Бізнес-завдання, які вирішує API
Завданням було зробити систему для компанії, яка здає зали в оренду. У цьому API реалізовано:
- Створення, редагування та видалення залів (разом із послугами, такими як Wi-Fi чи проєктор).
- Пошук вільних залів на потрібну дату та час.
- Бронювання залу з автоматичним розрахунком ціни (ціна змінюється залежно від часу: є ранкові знижки та націнки в пікові години).
- Аналітика: звіт, який показує, скільки грошей приніс кожен зал за обраний період.

## Як це працює 
Я розділив логіку на кілька частин:
- **Контролери (Controllers):** приймають запити від клієнта і повертають відповіді.
- **Репозиторії (Repositories):** відповідають за спілкування з базою даних.
- **Сервіси (Services):** тут лежить логіка розрахунку ціни, щоб не перевантажувати контролери.

Також я додав перевірку на накладання часу, щоб API не дозволяло двом людям забронювати один і той самий зал на однакові години. База даних при старті автоматично заповнюється початковими даними (3 зали та послуги до них).

## Технології
- C#, ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Swagger (для тестування методів)

## Як запустити проєкт

1. Завантажте проєкт на свій комп'ютер.
2. Відкрийте файл `appsettings.json` і вставте свої дані для підключення до PostgreSQL у рядок `DefaultConnection`:
   `"Host=localhost;Port=8888;Database=Conference_rooms;Username=postgres;Password=Ваш_пароль"`
3. Відкрийте Package Manager Console у Visual Studio і виконайте команду для створення бази даних:
   `Update-Database`
